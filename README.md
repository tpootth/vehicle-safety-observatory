# vehicle-safety-observatory

[Open dashboard](https://tpootth.github.io/vehicle-safety-observatory/)

Static portfolio dashboard deployed with GitHub Actions.

Car photos in `site/img/cars/` come from Wikimedia Commons, cropped and resized. Each keeps its own licence (CC BY-SA, CC BY or public domain); authors and links are listed under **Photo credits** on the site and in `site/cars.js`.
