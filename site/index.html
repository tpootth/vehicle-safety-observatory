Method & provenance

Good analysis starts with the join.

Source
Two official datasets

NHTSA vehicle ratings linked with EPA configurations. The scoped source contains 8,931 NHTSA and 14,283 EPA records.

NHTSA ratings · EPA downloads
Unit of analysis
Count a test once

Repeated vehicle-year records are collapsed to 511 frontal test IDs. Fuel linkage uses a crash-test VIN configuration when available, otherwise a name link. Raw VINs are excluded from this site.

Interpretation
Coverage is selective

Not every vehicle is tested or linked. Configurations can remain ambiguous. Grouped validation reduces reuse across related records; it does not remove all selection or matching uncertainty.

Data snapshot and reproducibility

This dashboard uses saved local analysis outputs. Charts recalculate the displayed sample when filters change; the underlying statistical models are not retrained in the browser. The paper-stage cohort and the integrated test-level cohort use different filters; this dashboard consistently uses the integrated test-level cohort.
